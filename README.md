# Project Documentation

## Swagger API Documentation

The Swagger documentation for this API is accessible at the `/api-docs` endpoint. You can view it by navigating to `http://<your-server-address>:<port>/api-docs` in your web browser. Replace `<your-server-address>` with your server's address and `<port>` with the port number your application is running on (default is 3000 if not specified otherwise).
